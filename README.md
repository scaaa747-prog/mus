# 🎵 Mus - Flutter Music Streaming App

A sleek, modern, and high-performance Music Streaming application built with Flutter & Material 3.

## ✨ Features
- 🎧 **Modern Dark UI**: Aesthetic dark interface with glassmorphism and purple neon accents.
- 📱 **Interactive Home Screen**:
  - Greeting header with profile avatar.
  - Category filter chips (Pop, Chill, Synthwave, Trending).
  - Horizontal trending playlists & albums carousel with one-tap play.
  - Recommended tracks list with cover, artist, and duration.
- 🎶 **Sticky Mini Player**:
  - Real-time animated progress bar.
  - Play/Pause toggle and favorite button.
  - Tap to expand into full screen Now Playing view.
- 🎼 **Full Screen Now Playing View**:
  - High-resolution album artwork with ambient glow.
  - Real-time scrubbable progress bar with elapsed/remaining timestamps.
  - Complete playback controls (Previous, Next, Play/Pause, Shuffle, Loop).
- 🔍 **Live Instant Search**:
  - Search by song title, artist, or genre in real-time.
- ⚡ **State Management**: Clean architecture powered by `Provider` and `ChangeNotifier`.

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://flutter.dev/docs/get-started/install) (version 3.0.0 or higher)
- Dart SDK

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/scaaa747-prog/mus.git
   cd mus
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app on emulator, connected device, or web:
   ```bash
   flutter run
   ```

4. Build release APK:
   ```bash
   flutter build apk --release
   ```
